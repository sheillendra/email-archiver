Gmail email archiving app for Windows

Email Archiever

Email Archiever is a Windows desktop application for Gmail users who want to archive old email messages from Gmail to their own computer.

Purpose: the app scans older Gmail messages, downloads the selected emails, saves verified local archive files, lets users read archived emails offline, and can optionally move successfully archived Gmail messages to Trash only after explicit user approval.

Google API use: Email Archiever uses Google OAuth and the Gmail API to read selected Gmail messages and perform the optional Trash action requested by the user.

App purpose

What Email Archiever does

Email Archiever is designed for people who need to reduce old Gmail storage, keep a searchable local copy of important email records, and access archived email files without relying on a mail server.

01

Scans older Gmail messages

Users choose an email age range, scan Gmail metadata, and review the message list before archiving.

02

Saves local archives

Messages are saved on the user's computer as organized email archive files per Gmail account.

03

Reads archived email offline

Users can search subjects, senders, recipients, and attachments from the local archive without reconnecting Gmail.

04

Optionally cleans Gmail

After successful local verification, users may choose to move archived Gmail messages to Trash.

Security and privacy

Gmail is changed only after the local archive is verified

Email files are written locally, hashed with SHA-256, and verified before any optional Gmail cleanup step. The cleanup option uses Trash, not permanent deletion.

Google OAuthGmail passwords are never requested or stored by the app.
Encrypted local tokensOAuth tokens are protected locally using Windows DPAPI.
Protected ArchiveOptional encrypted archive mode uses authenticated encryption for sensitive email files.
Restricted HTMLScripts, iframes, popups, and remote resources are blocked by default.

How it works

From old Gmail messages to a searchable local archive

1

Connect a Gmail account with Google OAuth.

2

Choose the email age range and local archive folder.

3

Scan Gmail and review the message list before archiving.

4

Archive, verify, and optionally move verified Gmail messages to Trash.

License

One-month trial, offline activation, read-only archive access

The full license is tied to a Machine ID and verified locally. If the license is inactive, the app can still open local archives in read-only mode so users do not lose access to email archives they already created.

Ready for review and use

Email Archiever clearly identifies its purpose: archiving old Gmail messages to local files on Windows.
