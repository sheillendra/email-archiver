Email Archiver

Privacy Policy

Last updated: August 18, 2026

Overview

Email Archiver is a Windows desktop application that helps Gmail users archive old email messages to local files on their own computer. The app does not provide an email archive server and does not upload email content, attachments, Gmail passwords, or local archive files to an Email Archiver server.

Data Processed

When a user connects Gmail, the app may process email metadata, message content, attachments, labels, Gmail message IDs, sender addresses, recipient addresses, dates, subjects, and estimated message sizes. This data is used to show scan results, create local archive files, and read archived email later.

The app may also store local account data on the user's computer, including email address, verification status, and password hash. Local app passwords are stored as hashes, not as plain text.

Google API Use

Email Archiver uses Google OAuth and the Gmail API to read selected Gmail messages and, only when requested by the user, move successfully archived messages to Trash after local verification is complete.

The app never asks for or stores the user's Gmail password. Google sign-in happens through the browser and Google's OAuth flow.

Local Storage

Email archives are stored in a folder chosen by the user. Archive files may be saved as Standard Archive files using the .eml format or as Protected Archive files using the encrypted .eml.enc format.

OAuth tokens are stored locally in encrypted form using Windows DPAPI for the current Windows user. Local account data, Gmail account registrations, scan metadata, license data, and trial data are also stored on the user's computer.

Protected Archive

Protected Archive uses authenticated encryption to protect local email content. The archive key is protected by Windows DPAPI. If the Protected Archive key file or the original Windows profile is lost, encrypted archives may not be recoverable.

Remote Images and Attachments

Remote images inside email are blocked by default to reduce tracking pixel risk. If the user chooses to load remote images, the app downloads images through a local cache with security restrictions.

Attachments can be opened or saved by the user. The app shows a warning before opening attachments because attachments can carry the same risks as other files on a computer.

Changes to Gmail

Email Archiver does not move Gmail messages to Trash before the local copy has been created and verified. The Trash option only runs when the user enables it and confirms the process. The app does not use permanent Gmail deletion.

Data Sharing

Email Archiver does not sell user data. Because the app works locally, email content and local archives are not sent to the app developer by the app. Data may still be processed by Google according to Google's policies when the user uses OAuth and the Gmail API.

User Responsibilities

Users are responsible for protecting archive folders, backups, license files, computer access, and Protected Archive key files. Users are also responsible for ensuring their use of the app complies with organizational policies, data retention requirements, and applicable law.

Policy Changes

This policy may be updated when features, licensing, email provider integrations, or legal requirements change. The latest version may be included with the app or published on the product website.
